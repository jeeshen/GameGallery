# Design

Reference: Orkan (https://orkan.framer.website/), selected by the user.

Full-bleed gameplay photography, saturated orange surfaces, near-black text, oversized bold sans-serif typography, and square album covers. Two-column album layout with a wide cover every fifth item. Mobile uses a single column. Each album opens a photo grid and a native fullscreen dialog; original photo proportions are preserved in the viewer.

Motion: slow image zoom on hover, CSS scroll reveals where supported, and a cinematic viewer with a blurred ambient version of each image behind the sharp frame. Arrow navigation slides the frame directionally and fades between memories. Content stays visible without animation; reduced-motion disables all effects.

Palette: orange oklch(0.68 0.21 38), ink oklch(0.19 0.025 38), near-black oklch(0.13 0.005 38), white oklch(0.97 0 0).
